# Agent Note：实施截止点正确的条件战法路由

Status: implemented

[English](2026-09-02-maoq-conditional-tactic-routing.md) | 中文

## 问题

共享战法目录让每种武器都具有明确身份并能失败关闭，但全周期汇总结果仍无法回答：在某个决策截止点已知的市场状态下，哪种合格武器更适用。让模型每次读取完整历史既慢、容易引入未来信息，也无法稳定复现。

## 决策

新增普通职责聚焦库 `dsh-market-tactic-routing`，不改造 agent loop。它拥有三类不可变、带内容地址的记录：成熟战法结果、条件战绩代际与确定性路由决策。

每项结果只有在持有窗口成熟后，才会归因到原始战略截止点和准确的目录战法版本。战绩单元按战法版本和六个有界环境维度建立索引：市场状态、情绪周期、板块结构、波动、拥挤度与执行质量。增量代际保留充分统计量和 alpha 为 0.2 的近期有效性平均，因此日常更新只读取新近可用的日期分区，不重新扫描完整历史。

路由器版本 `maoq-deterministic-tactic-router-v1` 冻结首个证据策略。主动战法必须拥有至少八个同环境成熟样本、为正的 95% 期望下界、双倍执行成本下仍为正的期望、不低于 50% 的成交率，以及为正的最终得分。得分综合目录环境匹配、条件下界、同环境证据、近期有效性、执行质量、成本稳健性、回撤、拥挤度、波动与样本不确定性。稳定排序最多输出三个主动战法，并附带分数组成、证据身份、拒绝原因、风险上限和现金下限。`defensive_no_trade` 始终独立可用；主动证据缺失或不足时由它胜出。

## 验证

- 单元 fixture 覆盖截止点归因、未来证据拒绝、重复拒绝、不可变持久化、有界增量读取、同环境资格、目录资格、稳定前三排序、研究战法仓位限制和防守回退。
- 该包可以独立编译，公开契约记录在成对的中英文包文档与子系统文档中。
- 路由身份包含战略快照、战绩、路由器版本、资格与目录证据，可用于确定性回放。

## 备选方案

**让 DSH 每次决策读取原始历史。** 这会增加延迟与 token 消耗，允许不一致计算，并隐藏截止点实际可用的证据。

**按全周期汇总收益路由。** 这会忽略状态依赖，把市场状态变化变成隐藏的选择错误。

**立即训练自适应学习器。** 当前结果流不足以支撑可信的在线学习。在衡量模型或学习器增量价值前，需要固定且带版本的基准。

## 后果

P1 现在可以向后续统帅提供小型且可回放的决策名单，同时不允许模型绕过资格或风险上限。固定阈值是预登记基准，不代表它们在经济上最优。P2 必须比较确定性路由与有界 DSH 选择；P4 必须提供封存的个股结果流，之后才允许提出任何模拟晋级结论。
