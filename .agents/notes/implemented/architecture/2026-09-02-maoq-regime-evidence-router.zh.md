# Agent Note：通过同状态证据阶梯路由战法

Status: implemented

[English](2026-09-02-maoq-regime-evidence-router.md) | 中文

## 问题

第一版确定性路由器要求一个六维精确环境单元中存在八个成熟观察。2022—2025 年回放显示，这种碎片化让 301 个 `risk_on_trend` 决策中有 263 个延续防守，尽管一项固定主动战法在该状态中取得了显著更高的收益。降低样本门槛会让估计更嘈杂，而强制参与则会在没有正向证据时虚构敞口。

## 决策

战法目录拥有每个战法家族适用的市场状态与情绪周期。自动化覆盖要求每种市场状态至少存在一个主动战法家族，避免目录遗漏悄然把某种状态变成永久防守。

路由器 v2 选择达到原有八样本门槛的最窄证据层：精确环境、市场状态加情绪周期、市场状态。它绝不跨市场状态合并观察。合并后的期望、方差、下界、胜率、盈亏比、成交率、翻倍成本结果和回撤依据单元充分统计量重新计算；近期有效性按各单元样本数加权。证据层越宽，环境对齐加分越小。每个主动名单仍然要求为正的 95% 期望下界、为正的翻倍成本期望、不低于 50% 的成交率，以及为正的路由得分。

每个候选与每日回放记录都会保存所选证据层。名单、资格引擎和动态回放版本同步推进，避免旧身份被误认为新策略。研究战法的模拟权限仍然为零。

## 验证

聚焦测试证明目录状态覆盖、精确环境选择、状态情绪与同状态合并、跨状态借用拒绝、证据层序列化、原有正向证据门禁，以及每日回放审计字段。生产历史 v3 回放包含 969 个交易日和 967 个可路由截止点。缺失或样本不足拒绝从 446 次降至 93 次，但名单仍然防守 929 次、主动 38 次；全部主动选择仍使用精确环境证据。总收益仍为 -3.14%，同期上证指数为 +9.26%。因此，P1 通过正确性与稀疏性验收，但没有通过参与验收。已经查看过的 2022—2025 年区间仍然只是开发证据，不是晋级留出集。

## 备选方案

**强制每日最低参与率。** 这会优化出手次数而不是胜利，并可能把缺失或负向证据转换为敞口。

**合并全部历史环境。** 这会让牛市证据在收缩或高波分歧期为战法取得资格，抹掉路由器本应尊重的主要矛盾。

**降低精确单元样本门槛。** 这不是利用更多可比观察，而是通过接受更不可靠的估计来增加名单。

**根据每次 2022—2025 年结果调整阶梯。** 该区间已经被查看，不能再成为封存留出集。P1 在读取后继结果前冻结证据阶梯；P2 的转移参数必须单独预登记。

## 后果

即使次要环境维度把精确单元切碎，路由器仍能学习战法在当前市场状态中的表现。同状态证据缺失、成本脆弱或统计上不为正时，它仍可持有现金。较宽证据层的环境针对性较弱，因此统帅可以看到其范围，分数贡献也更低。回放证明稀疏单元不是过度防守的主要原因；静态环境排除与同状态非正向证据现已成为主因。P2 必须先改造分状态作战策略，再投入精力处理切换滞后。
