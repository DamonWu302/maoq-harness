# Agent Note: MAOQ 确定性战略状态与有来源的方法归因

Status: implemented

[English](2026-08-31-maoq-strategic-state.md) | 中文

## 问题

不受约束的模型可以重命名市场状态、引用决策快照中不存在的观察，并在不说明证伪条件的情况下给出貌似合理的主要矛盾。要求模型提及《毛泽东选集》又增加了归因风险：它可能虚构篇名、引文或宿主无法审计的联系。P2 需要确定性观察在提示词和模型变化时保持稳定，同时保留有用解释。

## 决策

`@deepseek-ai/dsh-market-strategic-state` 负责带版本的确定性市场状态、情绪周期和板块战场特征。它接收一个不可变当前快照和显式历史快照，排序历史，在模型执行前计算全部标签，并给每个观察分配 `snapshot:<hash>#<path>` 证据地址。三类特征分别返回就绪或不可用结果。不可用组件会阻止可行动姿态，但不会抹掉其他就绪组件。

市场状态和情绪周期使用当前市场宽度与情绪观察。板块比较需要两个使用相同分类版本的历史快照，并计算强度、持续性、容量、催化支持、内部宽度、龙头质量、拥挤度和阻力。它确定性排序板块，不输出股票排名。

独立的 `StrategicInterpretationDraft` 包含主要矛盾、阻力最小的战场、支持证据、反证、切换条件、置信度、姿态和毛选方法应用。宿主拒绝空或未知证据引用、缺失反证、无效置信度、缺少切换条件、来自过期输入的可行动输出，以及来自残缺特征的可行动输出。决策时间和最大时效都是显式回放输入；校验器不读取环境时钟。

模型只能选择获准的 `MaoMethodId`，并说明本次应用、证据和适用边界。`MAO_METHOD_CATALOG` 在校验后加入来源篇目、来源 URL 和固定中文方法摘要。每条解析结果都标记为 `paraphrase`；模型提供的篇名或所谓引文都不能成为归因。目录把《反对本本主义》《改造我们的学习》《矛盾论》《实践论》《集中优势兵力，各个歼灭敌人》和《中国革命战争的战略问题》中的分析方法映射到研究工作流，但不声称这些篇目讨论证券交易。

`maoq_analyze_strategy` 按精确哈希加载快照，只向所选专家提供确定性特征，要求每份报告和综合都携带证据与方法引用，并运行独立的新风险审查。宿主保留确定性标签、解析归因，并把通过校验的姿态与风险结论组合起来。较底层的 `maoq_decide` 保留用于议事组运行时诊断，不是 P2 战略决策路径。

## 考虑过的替代方案

**让统帅直接从快照 JSON 推断全部状态。** 这会让标签随提示词和模型变化，阻止独立组件测试，并混合观察与解释。

**在提示词中放入毛选篇名和引文，再接收自由文本引用。** 提示词不是归因边界；模型仍可改变篇名、释义或证据联系。特定版本逐字引文还会增加校验负担，却不能改进决策契约。

**把不可用组件压缩成 `no_trade`，不保留部分结果。** 这会隐藏市场、情绪或板块历史究竟哪一部分失败，并降低数据质量诊断和回放比较的价值。

**在 P2 内开始股票排名。** 候选评分会绕过 P3 研究和 P4 风险边界。因此 P2 止于板块排序和战略姿态。

## 后果

相同的有序快照哈希和引擎版本会产生字节一致的确定性特征；提示词或模型变化只能影响分开存储的解释。每份被接受的解释都会给出支持与反对的快照字段、可证伪切换条件、置信度，以及至少一个有来源的方法应用。缺失历史、过期输入或虚构引用都会失败关闭。阈值是显式引擎策略：改变阈值需要提升版本并更新金标夹具。固定归因目录提高了可审计性，但有意放弃逐字引文和版本页码。盘中状态仍不属于该日级契约。
