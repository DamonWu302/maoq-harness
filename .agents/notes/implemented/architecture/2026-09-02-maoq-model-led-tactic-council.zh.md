# Agent Note: MAOQ 模型主导战术议会

Status: implemented

[English](2026-09-02-maoq-model-led-tactic-council.md) | 中文

## Problem

当前 P2 战术统帅同时把确定性 Top 3 路由当作量化建议和模型绝对白名单。模型可以调整短名单顺序，却不能把排名较低但已通过硬门槛的战法识别为阻力最小方向，也不能为当前主要矛盾选择所需专家或保留专家分歧。这使 harness 更像附带文字说明的脚本路由器，而不是模型主导的投资决策委员会。

放宽范围不能让模型文字绕过战法目录、数据硬门槛、晋级权限、执行证据或独立风控否决。

## Decision

路由暴露两个不同的宿主所有表面。`slate` 继续代表确定性量化建议。参谋全集包含所有通过硬可行性门槛的目录战法及防守项，并携带目录规则、状态匹配、适用板块、量化处置、证据和淘汰原因。

模型规划者从固定专家注册表中恰好选择两名相关专家：短线情绪、长线大牛趋势、短线快打执行、超跌修复和板块轮动。被选专家独立运行，输出结构化的支持、反对、证据、置信度和失效条件。

统帅把这些报告综合成作战计划，包含市场阶段、主要矛盾、受奖赏风格、姿态、主战法与可选辅战法、选股任务、证据、反证、置信度和失效条件。它还要记录是跟随还是推翻量化短名单。推翻必须给出明确理由和反证。

宿主只接受参谋全集中的战法 ID。确定性短名单之外的战法始终只能用于研究，模拟持仓权限为零，即使其目录晋级级别更高。模型不能改写入场、退出、晋级、证据、仓位上限或数据截止时间。

独立风控 Agent 审查完整作战计划和专家分歧。其否决仍是最终结论，并由确定性逻辑把动作替换为防守。完整提案、所选专家、报告、风控复核和派生权限都以内容寻址方式持久化，支持复盘和归因。

本切片止于股票排序和订单构造之前。`stockMissions` 表达下一层选股应该寻找什么，不是候选股或订单。

## Alternatives considered

**继续把确定性 Top 3 作为模型硬白名单。** 这能保持最小验证面，但违背使用推理 harness 的目的：模型无法质疑稀疏或滞后的评分卡，也无法针对当前市场选择不同攻击方式。

**允许模型发明或修改战法。** 这能提供最大自由度，却会破坏可复现性、晋级控制和可证伪归因。新战法必须经过源码目录和验证流程进入系统。

**每次运行全部专家。** 这能最大化覆盖，却增加延迟、Token 成本和相关叙事噪声。动态选择两名专家既保留多元判断，也迫使规划者先识别当前主要矛盾。

**让推翻量化建议的战法继承目录模拟权限。** 这会让文字成为执行策略的绕过通道。只有确定性路由资格才能授予现有的观察或模拟权限。

## Verification

- 模型把确定性短名单视为建议，并把完整硬可行参谋全集视为有边界的研究空间。
- 规划者从固定注册表中选择两名不重复专家，并且只运行这两名专家。
- 持久化提案包含专家报告和结构化作战计划，其中有主要矛盾、姿态、选股任务、证据、反证、置信度和失效条件。
- 跟随和推翻量化短名单可以区分；缺少理由和反证的推翻会被宿主验证拒绝。
- 未知、硬不可行或未注册战法会被拒绝。
- 路由外参谋战法被强制限定为研究范围、零模拟仓位和百分之百现金底线。
- 独立风控否决会确定性地产生防守结果，同时保留被拒提案用于归因。
- 模型可见提示词和模式由真实 Loader 组合测试或无 Key 快照测试覆盖，Token 用量包含规划者、所选专家、统帅和风控调用。

## Consequences

更宽的研究全集可能让模型偏爱有吸引力的叙事，而忽视已测量的条件期望。结构化分歧、强制推翻证据、路由外零权限、持久归因和后续结果评分能限制但不能消除这一风险。

两名专家可能遗漏相关视角。规划者选择会被持久化，因此遗漏的专业能力可以归因和评估；增加专家数量必须由延迟和结果证据推动，而不是凭直觉。
