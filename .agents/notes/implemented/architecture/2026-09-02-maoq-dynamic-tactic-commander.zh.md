# Agent Note: 增加有界动态战术统帅层

Status: implemented

[English](2026-09-02-maoq-dynamic-tactic-commander.md) | 中文

## 问题

MAOQ 需要在符合当前环境的战法之间进行选择，同时不能允许模型发明武器、重新解释市场数据截止点、晋级研究试验或隐藏切换成本。一项战法的全周期结果也不能说明系统是否只用每个决策时点可见的证据选择了正确战法。

## 决策

动态层继续由职责聚焦的库与工作流消费方组合，不 fork agent loop。战法目录拥有六项主动研究身份与 `defensive_no_trade`；路由库拥有成熟结果、条件战绩、确定性前三名单、经过宿主校验的统帅决策，以及这些记录的内容寻址持久化。

`maoq_select_tactics` 读取最新、已批准且当前仍新鲜的战略镜像，只加载截止点可见的最新战绩，并构建一份确定性名单。只有防守时直接创建零 Agent 决策。存在主动战法时恰好启动两个全新结构化输出 Agent：统帅从名单选择一个主战法和可选辅助战法，然后独立审查者批准或否决。宿主在发布决策前校验名单身份、证据归属、由晋级状态派生的范围、风险上限、现金下限和否决一致性。研究战法的模拟仓位上限始终为零。

战法实验室提供逐日推进回放，根据时点正确的个股、板块与原始执行交易时段重建每日战略代理特征。每个截止点只暴露观察窗口已经结束的结果，构建名单后才安排未来战法结果，不能提前读取，并采用固定 5 个基点切换成本。报告分开保留固定战法、平均分配、空仓、确定性路由、统帅建议与最终否决轨道，还会相对按日期对齐的上证综指、沪深 300、中证 500、中证 1000 和全市场等权收益归因每条轨道，包括状态切片与现金机会成本。缺失的历史统帅决策保持为明确的零覆盖，不进行插补。

2022-01-01 至 2025-12-31 的生产历史运行包含 969 个交易日、967 个可路由截止点和 968 个可比较收益观察。确定性路由选择防守 929 日、突破回踩 38 日；扣除切换成本后收益为 -3.14%，最大回撤为 7.49%，切换 66 次，并支付 3.30% 切换成本。固定突破回踩收益为 78.06%、最大回撤为 36.71%，平均分配收益为 -18.94%，空仓收益为零。上证综指收益为 9.26%，路由的几何超额为 -11.35%。在 `risk_on_trend` 中，路由在 301 个观察里只有 38 个处于主动状态，收益为 -1.77%，同期指数收益为 59.16%。它在 `risk_contraction` 中规避了部分损失，但不足以弥补错失的参与收益。历史统帅覆盖率为零，因此该结果否决确定性路由晋级模拟，证明 v1 把防守错误延伸到牛市状态，但仍不能测量 DSH 综合或否决的增量价值。

## 验证

单元覆盖证明名单成员约束、防守回退可用性、宿主派生范围、最终否决、内容身份、截止区间、陈旧状态拒绝、基准对齐、相对收益归因和现金机会成本核算。逐日推进测试修改一处未来权益值，并证明此前每份名单保持不变。真实 Loader 组合生成已批准的战略镜像，路由三项主动研究战法，恰好启动两个全新 Agent，并持久化一份不含模拟敞口的已批准研究范围决策。上游指数序列先通过其官方 Tushare 流水线补齐，再通过 `pnpm run maoq:p35-canary -- --start 2022-01-01 --end 2025-12-31 --chunk-sessions 30 --query-timeout-ms 300000` 运行生产回放。

## 备选方案

**让模型从文字中选择任意战法。** 这会允许未注册策略、隐藏实际试验数，并且无法复现某项战法为什么在一个截止点可用。

**选择近期全周期表现最好的战法。** 这会忽略状态依赖、鼓励追逐近期表现，也无法区分持久环境优势与单一有利状态。

**首先实现强化学习。** 延迟回报、稀疏环境样本、变化的市场结构和模型非确定性，使首版选择器无法充分归因与控制泄漏。有界战绩让证据可见性可以审计。

**在已经查看的 2022—2025 区间调整切换规则。** 这会把开发证据变成无效留出集。成本感知的后继版本必须先冻结转移策略，再使用分离的开发区间和封存留出集评估。

## 后果

标准日级选择只读取一份当前镜像和一份有界战绩，不重新扫描市场历史。模型可以解决有界冲突，却不能扩大名单、晋级战法或撤销否决。带基准回放表明 v1 的主要缺陷不只是切换成本：它在牛市状态样本中几乎一直持有现金，在风险收缩期降低回撤的同时放弃了更大的上涨收益。后继版本必须先为每种市场状态定义合格参与方式与证据标准，再冻结并在分离区间评估。任何主动战法或动态路由都不会因本实现获得模拟权限；只有在未用于调参的评估区间具备截止点正确的统帅记录后，才能测量 DSH 的历史增量价值。
