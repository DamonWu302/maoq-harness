# Agent Note: MAOQ 确定性战法资格

状态：已实现

[English](2026-09-01-maoq-tactic-eligibility.md) | 中文

## 问题

P2 可以识别市场状态、情绪周期和板块战场，但这些事实并不授权交易战法。如果允许 LLM 直接从叙事推导战法，未经测试的想法、不可用输入或诱人的回测标题数字都可能在个股排序前静默变成可行动结果。

## 决策

`@deepseek-ai/dsh-market-tactic-eligibility` 在 P2 与 P4 之间拥有带版本的不可变注册表和纯函数式失败关闭评估器。每条定义均声明晋级状态、证据等级、历史与持有要求、仓位上限、入场、退出、失效和执行要求。

状态适配与晋级是两个独立字段。匹配的 P2 事实可以让一条 `research` 战法成为 `research_only`，但不能让它进入 `eligibleTacticIds`。市场、情绪或板块证据缺失会使所有主动战法不合格。`defensive_no_trade` 是初始唯一合格定义，并始终保持零仓位回退。

首批主动研究定义是状态签名突破回踩、可成交情绪龙头和行业相对超跌修复。其公开证据与晋级阈值记录在 `docs/maoq-p3-tactic-research.zh.md`；引用证据强度不能替代 MAOQ 自己符合时点正确性的 A 股评估。

日线数据流水线在 `Asia/Shanghai` 19:00 自动更新，MAOQ 自动维护则在 19:15 首次检查并等待可用的当日不可变哈希。资格库只消费冻结的 P2 事实，不读取环境时钟。

## 考虑过的备选方案

- 允许统帅选择任意具名战法，仅依靠独立风险审查。这样可以在模型推理后发现部分错误输出，但不能形成可稳定回放的排序前门禁。
- 根据公开夏普数字直接把三个初始候选标记为合格。引用研究使用不同市场、组合结构、数据频率和执行假设。
- 在个股排序中直接编码单一偏好的突破或涨停策略。这会把状态识别、战法资格和个股选择压缩为一条无法独立测试的路径。

## 结果

- P3 状态匹配具有确定性、深度冻结、证据引用和可回放特性。
- 主动战法在经过显式源码控制的晋级前，不能用于模拟持仓。
- P4 必须先增加日线历史个股特征和共享执行模拟器，才能产出候选名单。
- 晋级变更需要新的已评审策略和评估产物，而不是修改提示词。

## 验证

单元测试覆盖匹配的研究状态、仅反转状态、不可用 P2 输入、防守回退、不可变定义，以及禁止把封死一字涨停视为成交。
