# Agent Note: 第二轮日线战法试验

Status: implemented

[English](2026-09-02-second-wave-daily-tactic-trials.md) | 中文

## 问题

MAOQ 首批三个战法试验未达到晋级阈值。继续调整其突破、涨停和修复参数会增加选择偏差，却不能检验不同的收益来源。

## 决策

固定研究注册表新增三个日线加板块试验：相关性聚类板块轮动、板块残差强势和低波板块领涨。它们共用现有 A 股次日开盘执行策略、成本、按时间折、容量审计、Deflated Sharpe 计算及套件级 PBO 计算。

特征记录使用 schema 版本 2。它增加个股 20 交易时段实现波动率、时点正确板块 1 与 20 交易时段收益、板块实现波动率，以及规范顺序的板块间 20 交易时段相关性对。增量引擎只保留复现批处理结果所需的有界板块及个股观察。

三个试验每五个交易时段接受一次新入场。相关性聚类使用预登记的 0.75 阈值。模型不能通过研究工具改变阈值、组合构建、入场频率或持有期。全部六个试验都计入 `attemptedTrials`，且封存留出集完成前均不能离开 `research`。

## 考虑过的替代方案

**调整首批三个战法。** 这会在已观察失败附近搜索，并低估实际试验数，因此注册表保留其版本和结果不变。

**采用公开多空或盘中实现。** 其执行假设不符合纯日线、只多和 T+1 策略，因此公开结果只能作为动机或比较证据。

**增加通用优化器。** 在单项信号证明正向扣费证据前，因子分配器会降低归因和试验计数的可靠性，因此每个新试验仍是固定透明规则。

## 后果

同一次生产历史读取会比较六项固定试验，并把 DSR 尝试试验数从三提高到六。由于每个获准交易时段都要计算个股波动率和板块相关性，特征计算成本会上升。即使新战法结果为负，报告的 2022—2025 年结果仍作为研究证据保留；失败试验保持可见，不能由相邻参数变体覆盖。
