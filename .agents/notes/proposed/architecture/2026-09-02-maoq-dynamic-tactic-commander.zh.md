# Agent Note: 增加动态战术统帅层

Status: proposed

[English](2026-09-02-maoq-dynamic-tactic-commander.md) | 中文

## 问题

MAOQ 已有确定性战略状态特征、固定战法实验室、唯一共享战法目录、截止点正确的条件战绩，以及确定性前三路由器。它仍然没有消费该名单的有界 DSH 统帅、没有把模型选择与确定性路由分开归因的宿主契约，也没有封存的个股结果比较来衡量模型辅助选择是否增加价值。

## 提案

完成一个由普通职责聚焦包组装的 P3.5 动态战术统帅层，不 fork agent loop。已实施的 P0 基础让一个目录拥有带版本的战法身份、晋级状态、环境要求、执行约束、失效条件和风险上限。已实施的 P1 基础增加不可变的成熟结果、有界条件战绩与确定性路由。P2 将增加有界 DSH 选择、宿主校验、回放比较与归因，同时不把这些逻辑移入 agent loop。

首个覆盖目标包含十个主动战法族与 `defensive_no_trade`。路由器只读取已成熟且截止点正确的结果，产出一份确定性前三名单，其中包含分数组成、不确定性、拒绝原因、风险上限和现金下限。DSH 统帅最多可以从名单选择一个主战法和一个辅助战法。宿主校验会拒绝未知、不合格、陈旧、超预算或与晋级状态不一致的选择，然后独立审查者才能批准或否决结果。

首个学习机制采用延迟的条件战绩更新，而非强化学习。战法结果只有在其声明持有窗口结束后才能更新战绩。战法规则、环境分桶、分数变换、权重、衰减或风险预算的变化都会创建新的带版本试验身份。

## 备选方案

**让模型从文字中选择任意战法。** 这保留灵活性，却会允许未注册策略、隐藏实际试验数，并且无法复现某项战法为什么在一个截止点可用。

**选择近期全周期表现最好的战法。** 这会忽略状态依赖、鼓励追逐近期表现，也无法区分持久的环境优势与单一有利状态。

**首先实现强化学习。** 延迟回报、稀疏状态样本、变化的市场结构和模型非确定性，使首版选择器无法充分归因与控制泄漏。在考虑更自适应的学习器前，有界战绩与路由器可以先建立可审计证据。

**先建立大量战法再开发路由器。** 更多重叠变体会增加选择偏差，却仍然缺少同一个决策约定。该提案只增加足够覆盖主要机会来源的独立家族，然后先测量动态选择，再继续扩展。

## 验收标准

- 一个带版本目录提供研究、资格、路由、统帅综合、选股和审计输出所消费的全部战法 ID 与约束。
- 统帅 schema 只接受目录战法 ID，分离研究与模拟范围，并且不能覆盖宿主资格或最终风险否决。
- 回放使用截止点正确的战略事实、成熟结果、战绩身份、路由器版本和来源哈希重建每份名单，不能使用未来数据。
- 评估在扣除切换与执行成本后比较固定战法、平均分配、确定性路由、DSH 辅助路由和最终风险否决结果。
- 标准日级决策使用有界战绩读取与最小充分议事组，而不是扫描完整历史或调用全部专家。
- 在根据下一段晋级时期评估路由权重、提示词和模型路线前，必须先冻结该时期。

## 风险

环境分桶可能切碎样本，使不确定性压倒主动选择。固定分数权重可能编码较弱先验，频繁战法切换则可能消耗表面优势。模型也可能只增加有说服力的解释，却没有可测量的选择价值。因此，该设计保留 `defensive_no_trade`，报告不确定性与切换成本，分别比较确定性和模型辅助选择器，并要求新的封存留出集才能晋级模拟。
