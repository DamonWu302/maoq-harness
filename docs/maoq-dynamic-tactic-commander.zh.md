# MAOQ 动态战术统帅层

[English](maoq-dynamic-tactic-commander.md) | 中文

## 摘要

动态战术统帅层把确定性战略状态、多样且固定的战法目录，以及每个战法已经成熟的条件战绩转化为一项有界的每日选择。它可以选择一个主战法、一个辅助战法或 `defensive_no_trade`；模型不能发明战法、削弱资格条件、改变执行规则或绕过独立风险否决。

<a id="problem"></a>
## 问题

一项战法的全周期结果只能测量一件孤立武器，不能测量 MAOQ 是否用当时可见的信息识别主要矛盾并选择正确武器。因此，动态层必须保留固定、可审计的战法实现，同时根据市场状态、情绪周期、板块结构、执行质量和证据不确定性对其进行条件评估与路由。

共享目录对齐六项固定研究试验、资格评估与通用议事组的战法枚举。由宿主拥有的条件战绩与确定性路由器把相似状态下的成熟证据转化为有界前三名单；`maoq_select_tactics` 再执行受约束的统帅综合、宿主校验和独立风险否决。逐日推进回放已经能够衡量确定性路由，但历史区间没有模型决策记录，因此还不能测量 DSH 综合与否决的增量价值。

<a id="tactic-coverage"></a>
## 战法覆盖

首版动态目录以十个主动战法族加防守为目标。该数量是覆盖目标，不是增加相邻参数变体的许可；每个实现仍是带版本试验，并计入多重检验修正。

| 战法族 | 周期 | 独立机会来源 | 初始处理 |
|---|---|---|---|
| 状态签名突破与受控回踩 | 中线 | 板块确认下的趋势扩张 | 保留，修改只能创建新版本 |
| 平台整理与二次上攻 | 中短线 | 完整主线内部的供给收缩 | 新增 |
| AH52 阻力路径 | 中线 | 市场与板块上方套牢供给收缩 | 新增 |
| 板块集群轮动 | 中线 | 共振板块群之间的资金迁移 | 保留为负面研究证据，等待重新设计 |
| 板块残差强势 | 中线 | 合格板块内部的个股独立延续 | 保留为负面研究证据，等待重新设计 |
| 低波板块领涨 | 中线 | 不追逐加速的防守领涨 | 保留为负面研究证据，等待重新设计 |
| 可成交情绪龙头 | 短线 | 涨停生态的启动或加速初段 | 用单独注册的假设替代失败的收盘追涨形式 |
| 核心首次分歧修复 | 短线 | 完整主线内部第一次受控分歧 | 最先新增 |
| 首板延迟价格发现 | 短线 | 广泛共振且可成交首板后的延迟定价 | 证明日线涨停制度重建后新增 |
| T+1 恐慌修复 | 短线 | 高换手抛售后的衰竭与修复 | 采用至少两个交易时段的执行路径新增 |
| 防守空仓 | 防守 | 证据或优势不足时保留选择权 | 始终保留 |

政策和新闻属于催化证据，而非独立买入信号。只有来源质量、传导路径、板块价格确认、宽度、容量和截止点资格全部通过时，催化才能提高对应战法的环境分数。

<a id="decision-architecture"></a>
## 决策架构

```text
immutable daily snapshot
  -> deterministic strategic state
  -> unified tactic catalog and hard eligibility
  -> context-conditioned tactic scorecard
  -> deterministic top-three routing slate
  -> selected DSH specialists and commander synthesis
  -> host validation and independent risk veto
  -> tactic-specific stock ranking and next-session paper execution
  -> matured outcome attribution and scorecard update
```

一个目录拥有战法身份、家族、版本、晋级状态、环境要求、入场与退出规则、失效条件、执行要求和风险上限。战法实验室、资格评估器、路由层、统帅 schema、选股器和审计报告都消费该目录，不再分别维护战法联合类型。

确定性资格层先剔除与当前事实冲突的战法。路由器随后只对获准的研究或已晋级战法排序，并显式保留晋级状态。研究战法可以进入研究名单，但不能创建模拟仓位；即使主动战法排名第一，`defensive_no_trade` 仍保持可用。

<a id="dynamic-scorecard"></a>
## 动态战绩

战绩按照战法版本和有界环境建立索引：市场状态、情绪周期、板块结构、波动区间、拥挤区间和执行质量区间。每个单元保存充分统计量，用于计算样本数、扣费期望及其 95% 下界、胜率、盈亏比、回撤、成交率、双倍成本结果、alpha 为 0.2 的近期有效性平均、观察截止点和精确来源身份。证据不足保持为不确定性，不能变成零收益。

首版路由器使用一项预登记且带版本的分数，不采用模型编写的权重：

```text
route score =
  state fit
  + conditional expectancy lower bound
  + sector and emotion alignment
  + recent out-of-sample effectiveness
  + execution, liquidity, and catalyst confirmation
  - drawdown, crowding, transition, and uncertainty penalties
```

v2 实现选择达到八个成熟样本的最窄证据层：精确环境，其次是市场状态加情绪周期，最后是同一市场状态。证据绝不跨越市场状态边界。较宽证据层依据单元充分统计量重新计算收益、风险和执行指标，按样本数加权近期有效性，并获得较低的环境对齐加分。为正的 95% 期望下界、为正的翻倍成本期望、不低于 50% 的成交率，以及为正的最终得分仍然是硬要求。权重、环境分桶、证据阶梯、衰减规则或风险预算的变化都会创建新的路由器版本与试验身份。路由器返回前三个获准战法、分数组成、证据层、证据引用、不确定性、最大风险预算、现金下限和拒绝原因；它不选择股票。

<a id="commander-contract"></a>
## 统帅约定

DSH 议事组解决确定性分数无法单独裁决的冲突：哪个矛盾是主要矛盾、状态是否正在转变、独立政策或新闻证据是否确认板块路径，以及优势是否清晰到足以行动。统帅接收有界的前三名单，最多选择一个主战法和一个辅助战法。

结构化决策记录快照、战略状态与路由器版本、主要矛盾、阻力最小战场、选择与拒绝的战法 ID、分数证据、研究或模拟范围、风险预算、现金权重、置信度、反证、转变条件和失效条件。`tacticId` 是统一目录中的枚举，不是自由文本。

宿主会拒绝未知或不合格战法、超过战法上限的风险预算、被表述为模拟行动的研究战法、陈旧证据、不一致现金分配，或缺少必要反证的决策。独立审查者在综合后运行，可以把完整结果改为 `defensive_no_trade`；统帅不能撤销该否决。

标准模式读取当前战略镜像与确定性名单，再运行统帅综合和独立风险审查。深度模式只增加解决实质分歧所需的专家，例如情绪、政策宏观、板块战场或战法选择；它不会调用全部专家，也不会在每次日级决策时重新扫描完整历史。

<a id="learning-and-replay"></a>
## 学习与回放

首版使用延迟的条件战绩更新，不使用强化学习。交易时段 `t` 的决策只读取其截止点前可用的观察与成熟结果，不早于 `t+1` 执行，并且只在所选战法声明的观察窗口结束后更新战绩。未结束或不完整结果不能提前进入选择器，模型也不能根据已实现结果修改战法参数。

2022—2025 年历史的汇总结果已经被查看，因此它属于开发语料。逐时回放仍可检验每项模拟决策是否只使用先前信息，但不能充当封存晋级留出集。最终晋级需要一个单独冻结的时期，该时期不能用于选择战法、路由特征、权重、提示词或模型路线。

回放比较 `defensive_no_trade`、全部战法平均分配、每项固定战法、确定性路由器、路由器加 DSH 统帅，以及风险否决后的完整结果。它把每个可比交易日与上证指数、沪深300、中证500、中证1000和明确标注的全A等权总体对齐。每项比较报告几何超额收益、年化超额收益、信息比率、Beta、上涨与下跌捕获率、空仓机会成本、避免损失，以及按决策日市场状态拆分的策略与基准归因。看见未来结果的神谕只用于诊断，绝不是可部署基准。

<a id="acceptance-criteria"></a>
## 验收标准

1. 战法实验室、资格评估器、路由器、统帅和选股器消费同一个带版本战法目录。
2. 统帅不能返回未知战法 ID、改变战法参数或通过文字晋级研究战法。
3. 每次路由都能由其快照、状态、目录、战绩、路由器版本和成熟结果截止点复现。
4. 每日回放只使用该决策截止点前可用的数据、新闻、板块成员和已经结束的战法结果。
5. 输出保留前三名单、分数组成、拒绝战法、不确定性、现金权重和失效条件。
6. `defensive_no_trade` 作为真实行动参与竞争；在扣除不确定性与成本后没有正向证据时必须使用它。
7. 宿主校验与独立风险审查都失败关闭，否决不能显示为批准。
8. 评估分别归因战略状态、确定性路由、DSH 综合、选股、执行和风险否决的价值，并让相同轨道与完整真实指数及等权基准比较。
9. 动态选择器扣除切换成本后必须优于预登记固定、平均分配、包含空仓和市场指数基准，才能晋级模拟；[P3 战法研究](maoq-p3-tactic-research.zh.md)中的封存留出策略仍然具有约束力。
10. 标准日级运行不扫描完整历史或调用全部专家；有界战绩读取、token 使用、延迟和不可用证据均可观察。

<a id="implementation-sequence"></a>
## 动态层 P0-P2 计划

这些阶段属于 P3.5，不替代[路线图](maoq-roadmap.zh.md)中的项目级 P0-P5 里程碑。

| 阶段 | 状态 | 主要交付物 | 验收结论 |
|---|---|---|---|
| P0——唯一战法事实 | 已完成 | 带版本目录、派生研究 ID、模型 schema 和失败关闭宿主校验 | 目录、实验室、研究工具和议事组共享同一身份；聚焦测试与真实 Loader 组合通过 |
| P1——条件战绩与路由 | 已完成 | 成熟结果、不可变条件战绩、确定性前三名单和防守回退 | 截止点、内容身份、证据不足与未来数据拒绝均有自动化覆盖 |
| P2——统帅与归因 | 已实施，未晋级 | `maoq_select_tactics`、统帅决策记录、独立否决、逐日推进回放和真实指数归因 | 确定性回放扣费后未优于空仓和上证指数；历史模型覆盖为零，不能晋级模拟 |

### P0——唯一战法事实与失败关闭使用

**状态：已实施。** `dsh-market-tactic-eligibility` 拥有六个主动战法 ID、`defensive_no_trade`、对应版本、家族、晋级状态、环境要求、执行要求和风险策略。战法实验室从该目录派生研究 ID 与版本映射，模型侧研究工具直接消费派生 ID 列表。通用议事组把同一组 ID 暴露为枚举；宿主校验会拒绝未知战法、不匹配的 `no_trade`、未知行动，以及被表述为 `paper_trade` 的研究战法。

当资格评估器、研究实验室、研究工具和议事组之间的目录身份与版本无法漂移，非法模型输出在宿主解析器失败，并且真实 Loader 组合能让注册战法完整经过综合与否决时，P0 通过验收。P0 不声称已经具备条件战绩、前三路由或动态战法选择。

### P1——条件战绩与确定性路由

**状态：已实施。** `dsh-market-tactic-routing` 把已经结束的结果归因到原始战略截止点与当前目录版本，持久化带内容地址的结果和不可变聚合代际，并拒绝未来可见证据。带版本的确定性路由器只读取有界战绩，应用硬资格门槛与固定证据阈值，并输出前三战法、分数组成、证据引用、拒绝原因、风险上限和现金下限。

每项结果、战绩和路由都具有内容身份；开闭截止区间更新阻止未完成结果向前泄漏；有界日期分区避免读取完整历史；条件证据缺失、样本不足、成本脆弱或成交质量较差时，`defensive_no_trade` 胜出。确定性记录无需调用模型即可回放与比较；P2 负责模型辅助比较。

### P2——DSH 统帅、否决与逐日归因

**状态：已实施，未通过晋级。** `maoq_select_tactics` 只向 DSH 统帅提供确定性的前三名单、防守回退和最小充分证据。统帅最多选择一个主战法和一个辅助战法；宿主校验拥有范围与风险上限，独立审查者保留最终否决权。结构化决策、token 使用、路由身份和最终否决会被持久化，以供后续归因。

2022-01-01 至 2025-12-31 的时点正确回放覆盖 969 个交易日，其中 967 日可路由。确定性路由选择防守 929 日、突破回踩 38 日；计入 5 个基点切换成本后收益为 -3.14%、最大回撤为 7.49%，共切换 66 次并支付 3.30% 的切换成本。同期固定突破回踩收益为 78.06%、最大回撤为 36.71%，平均分配收益为 -18.94%，空仓收益为 0。结果表明当前路由降低了回撤，但过度空仓和切换共同导致它未达到模拟晋级标准。

基准底线使用 968 个对齐收益观察。上证指数收益为 9.26%，因此确定性路由落后 11.35%。在 301 个 `risk_on_trend` 决策日中，路由只有 38 日主动出击并亏损 1.77%，同期上证指数上涨 59.16%；在 366 个 `risk_contraction` 决策日中，路由亏损 0.80%，同期指数下跌 13.14%。防守能够避开收缩期损失，但选择器错误地把空仓延续到了主要风险偏好机会集合。

该历史区间没有已记录的 DSH 统帅决策，因此模型建议与最终否决轨道都回退为空仓，模型覆盖率为 0。该回放只能否决当前确定性动态路由，不能证明模型选择无效，也不能用同一 2022—2025 区间调参后再宣称通过。状态证据后继版定义由目录拥有的状态与情绪覆盖，以及不跨状态的证据阶梯。它有意不强制参与：同状态证据缺失或扣除成本后为负时，仍然选择防守。切换滞后、最短持有期和成本感知转移属于下一项独立决策，必须先冻结，再使用分离的开发区间和封存留出集评估。

### 路由纠偏 P0-P2

以下阶段用于处理上文发现的过度防守问题，与原 P3.5 交付阶段相互独立。

| 阶段 | 状态 | 交付物 | 验收标准 |
|---|---|---|---|
| P0——诊断参与 | 已完成 | 分状态基准、名单计数、拒绝原因计数与固定战法对比 | 证明防守源于合理状态判断还是路由稀疏 |
| P1——状态证据路由 | 已实施，验收失败 | 目录拥有的状态／情绪覆盖、精确环境 → 状态情绪 → 同状态证据阶梯、可审计证据层 | 未跨状态泄漏且减少稀疏证据拒绝，但主动参与没有增加 |
| P2——分状态作战策略 | 已实施；纠偏验收通过，未晋级 | 分离硬可行性与状态适配先验、比较同状态可行战法、归因机会成本，并加入带版本的转移控制 | 主动选择从 38 次增至 132 次，净收益从 -3.14% 提升至 +2.70%，但仍落后上证指数与固定突破基线 |

v4 纠偏回放仍包含 969 个交易日和 967 个可路由截止点。原始名单选择防守 835 次、突破回踩 72 次、超跌修复 59 次、低波板块领涨 1 次。转移控制轨道在 968 个可比较收益日中主动 132 日；计入 5 个基点切换成本后收益为 +2.70%、最大回撤为 9.35%，累计支付 9.90% 切换成本。它同时优于 P1 的 -3.14% 与 v4 无状态路由的 +1.58%。然而，转移只改变了一个交易日的选择：最短持有保留发生 1 次，挑战者分数优势切换 0 次。因此，其表面收益增量只是开发证据，不能视为对五日和 0.03 参数的广泛验证。

纠偏在经济上仍未完成。上证指数收益为 +9.26%，质量总体等权基准为 +62.00%，固定突破回踩为 +78.06%。在 301 个 `risk_on_trend` 观察中，纠偏路由主动 81 日、收益 +16.61%，而上证指数收益 +59.16%。它把收缩期表现改善到 -8.37%，优于指数的 -13.14%；最大回撤 9.35%，也显著低于指数的 25.61%，但上行参与不足仍是主要矛盾。基准归因还显示，相对等权总体，空仓交易日产生 18.94% 的机会成本。因此，P2 通过了预登记纠偏标准——净收益优于 P1，且没有让所有状态同时恶化——但仍不能晋级模拟，也不能把已经查看的区间用作封存留出集。

当每项模型辅助决策均符合截止点且可回放，未知或未晋级行动失败关闭，标准模式避免完整历史扫描和非必要专家，并且完整选择器扣除切换成本后优于预登记的固定及含空仓基准，才允许晋级模拟，P2 通过验收。

## 开发注记

P0 至 P2 的宿主能力、硬软门禁分离、同状态路由、转移归因和无未来数据回放均已实施。路由纠偏 P2 修复了大部分过度防守缺陷，并让开发区间收益转正，但仍落后上证指数，对 `risk_on_trend` 的捕获不足；模型辅助增量价值也仍未测量。下一项试验必须使用时点正确信息提高牛市参与与敞口，同时保留收缩期防守，并在新的预登记开发区间及后续封存留出集上评估。已经查看的 2022—2025 年区间不能继续用于调阈值或授权模拟晋级。
