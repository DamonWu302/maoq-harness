# MAOQ 动态战术统帅层

[English](maoq-dynamic-tactic-commander.md) | 中文

## 摘要

动态战术统帅层把确定性战略状态、多样且固定的战法目录，以及每个战法已经成熟的条件战绩转化为一项有界的每日选择。它可以选择一个主战法、一个辅助战法或 `defensive_no_trade`；模型不能发明战法、削弱资格条件、改变执行规则或绕过独立风险否决。

<a id="problem"></a>
## 问题

一项战法的全周期结果只能测量一件孤立武器，不能测量 MAOQ 是否用当时可见的信息识别主要矛盾并选择正确武器。因此，动态层必须保留固定、可审计的战法实现，同时根据市场状态、情绪周期、板块结构、执行质量和证据不确定性对其进行条件评估与路由。

共享目录对齐六项固定研究试验、资格评估与通用议事组的战法枚举。由宿主拥有的条件战绩与确定性路由器现已把相似状态下的成熟证据转化为有界前三名单。剩余缺口是模型辅助选择与归因：DSH 统帅还没有消费该名单，也没有逐日推进比较来分离综合与否决的增量价值。

<a id="tactic-coverage"></a>
## 战法覆盖

首版动态目录以十个主动战法族加防守为目标。该数量是覆盖目标，不是增加相邻参数变体的许可；每个实现仍是带版本试验，并计入多重检验修正。

| 战法族 | 周期 | 独立机会来源 | 初始处理 |
|---|---|---|---|
| 状态签名突破与受控回踩 | 中线 | 板块确认下的趋势扩张 | 保留，修改只能创建新版本 |
| 平台整理与二次上攻 | 中短线 | 完整主线内部的供给收缩 | 新增 |
| AH52 阻力路径 | 中线 | 市场与板块上方套牢供给收缩 | 新增 |
| 板块集群轮动 | 中线 | 共振板块群之间的资金迁移 | 保留为负面研究证据，等待重新设计 |
| 板块残差强势 | 中线 | 合格板块内部的个股独立延续 | 保留为负面研究证据，等待重新设计 |
| 低波板块领涨 | 中线 | 不追逐加速的防守领涨 | 保留为负面研究证据，等待重新设计 |
| 可成交情绪龙头 | 短线 | 涨停生态的启动或加速初段 | 用单独注册的假设替代失败的收盘追涨形式 |
| 核心首次分歧修复 | 短线 | 完整主线内部第一次受控分歧 | 最先新增 |
| 首板延迟价格发现 | 短线 | 广泛共振且可成交首板后的延迟定价 | 证明日线涨停制度重建后新增 |
| T+1 恐慌修复 | 短线 | 高换手抛售后的衰竭与修复 | 采用至少两个交易时段的执行路径新增 |
| 防守空仓 | 防守 | 证据或优势不足时保留选择权 | 始终保留 |

政策和新闻属于催化证据，而非独立买入信号。只有来源质量、传导路径、板块价格确认、宽度、容量和截止点资格全部通过时，催化才能提高对应战法的环境分数。

<a id="decision-architecture"></a>
## 决策架构

```text
immutable daily snapshot
  -> deterministic strategic state
  -> unified tactic catalog and hard eligibility
  -> context-conditioned tactic scorecard
  -> deterministic top-three routing slate
  -> selected DSH specialists and commander synthesis
  -> host validation and independent risk veto
  -> tactic-specific stock ranking and next-session paper execution
  -> matured outcome attribution and scorecard update
```

一个目录拥有战法身份、家族、版本、晋级状态、环境要求、入场与退出规则、失效条件、执行要求和风险上限。战法实验室、资格评估器、路由层、统帅 schema、选股器和审计报告都消费该目录，不再分别维护战法联合类型。

确定性资格层先剔除与当前事实冲突的战法。路由器随后只对获准的研究或已晋级战法排序，并显式保留晋级状态。研究战法可以进入研究名单，但不能创建模拟仓位；即使主动战法排名第一，`defensive_no_trade` 仍保持可用。

<a id="dynamic-scorecard"></a>
## 动态战绩

战绩按照战法版本和有界环境建立索引：市场状态、情绪周期、板块结构、波动区间、拥挤区间和执行质量区间。每个单元保存充分统计量，用于计算样本数、扣费期望及其 95% 下界、胜率、盈亏比、回撤、成交率、双倍成本结果、alpha 为 0.2 的近期有效性平均、观察截止点和精确来源身份。证据不足保持为不确定性，不能变成零收益。

首版路由器使用一项预登记且带版本的分数，不采用模型编写的权重：

```text
route score =
  state fit
  + conditional expectancy lower bound
  + sector and emotion alignment
  + recent out-of-sample effectiveness
  + execution, liquidity, and catalyst confirmation
  - drawdown, crowding, transition, and uncertainty penalties
```

v1 实现要求八个同环境成熟样本、为正的 95% 期望下界、为正的翻倍成本期望、不低于 50% 的成交率，以及为正的最终得分。它在回放前冻结精确变换和权重。权重、环境分桶、衰减规则或风险预算的变化都会创建新的路由器版本与试验身份。路由器返回前三个获准战法、分数组成、证据引用、不确定性、最大风险预算、现金下限和拒绝原因；它不选择股票。

<a id="commander-contract"></a>
## 统帅约定

DSH 议事组解决确定性分数无法单独裁决的冲突：哪个矛盾是主要矛盾、状态是否正在转变、独立政策或新闻证据是否确认板块路径，以及优势是否清晰到足以行动。统帅接收有界的前三名单，最多选择一个主战法和一个辅助战法。

结构化决策记录快照、战略状态与路由器版本、主要矛盾、阻力最小战场、选择与拒绝的战法 ID、分数证据、研究或模拟范围、风险预算、现金权重、置信度、反证、转变条件和失效条件。`tacticId` 是统一目录中的枚举，不是自由文本。

宿主会拒绝未知或不合格战法、超过战法上限的风险预算、被表述为模拟行动的研究战法、陈旧证据、不一致现金分配，或缺少必要反证的决策。独立审查者在综合后运行，可以把完整结果改为 `defensive_no_trade`；统帅不能撤销该否决。

标准模式读取当前战略镜像与确定性名单，再运行统帅综合和独立风险审查。深度模式只增加解决实质分歧所需的专家，例如情绪、政策宏观、板块战场或战法选择；它不会调用全部专家，也不会在每次日级决策时重新扫描完整历史。

<a id="learning-and-replay"></a>
## 学习与回放

首版使用延迟的条件战绩更新，不使用强化学习。交易时段 `t` 的决策只读取其截止点前可用的观察与成熟结果，不早于 `t+1` 执行，并且只在所选战法声明的观察窗口结束后更新战绩。未结束或不完整结果不能提前进入选择器，模型也不能根据已实现结果修改战法参数。

2022—2025 年历史的汇总结果已经被查看，因此它属于开发语料。逐时回放仍可检验每项模拟决策是否只使用先前信息，但不能充当封存晋级留出集。最终晋级需要一个单独冻结的时期，该时期不能用于选择战法、路由特征、权重、提示词或模型路线。

回放比较 `defensive_no_trade`、全部战法平均分配、每项固定战法、确定性路由器、路由器加 DSH 统帅，以及风险否决后的完整结果。报告包含扣费收益、回撤、换手、切换成本、条件遗憾、空仓贡献、战法集中度、状态归因、被拒交易贡献、token 使用、延迟和模型路线差异。看见未来结果的神谕只用于诊断，绝不是可部署基准。

<a id="acceptance-criteria"></a>
## 验收标准

1. 战法实验室、资格评估器、路由器、统帅和选股器消费同一个带版本战法目录。
2. 统帅不能返回未知战法 ID、改变战法参数或通过文字晋级研究战法。
3. 每次路由都能由其快照、状态、目录、战绩、路由器版本和成熟结果截止点复现。
4. 每日回放只使用该决策截止点前可用的数据、新闻、板块成员和已经结束的战法结果。
5. 输出保留前三名单、分数组成、拒绝战法、不确定性、现金权重和失效条件。
6. `defensive_no_trade` 作为真实行动参与竞争；在扣除不确定性与成本后没有正向证据时必须使用它。
7. 宿主校验与独立风险审查都失败关闭，否决不能显示为批准。
8. 评估分别归因战略状态、确定性路由、DSH 综合、选股、执行和风险否决的价值。
9. 动态选择器扣除切换成本后必须优于预登记固定基准和平均分配，才能晋级模拟；[P3 战法研究](maoq-p3-tactic-research.zh.md)中的封存留出策略仍然具有约束力。
10. 标准日级运行不扫描完整历史或调用全部专家；有界战绩读取、token 使用、延迟和不可用证据均可观察。

<a id="implementation-sequence"></a>
## 动态层 P0-P2 计划

这些阶段属于 P3.5，不替代[路线图](maoq-roadmap.zh.md)中的项目级 P0-P5 里程碑。

### P0——唯一战法事实与失败关闭使用

**状态：已实施。** `dsh-market-tactic-eligibility` 拥有六个主动战法 ID、`defensive_no_trade`、对应版本、家族、晋级状态、环境要求、执行要求和风险策略。战法实验室从该目录派生研究 ID 与版本映射。通用议事组把同一组 ID 暴露为枚举；宿主校验会拒绝未知战法、不匹配的 `no_trade`、未知行动，以及被表述为 `paper_trade` 的研究战法。

当资格评估器、研究实验室和议事组之间的目录身份与版本无法漂移，非法模型输出在宿主解析器失败，并且真实 Loader 组合能让注册战法完整经过综合与否决时，P0 通过验收。P0 不声称已经具备条件战绩、前三路由或动态战法选择。

### P1——条件战绩与确定性路由

**状态：已实施。** `dsh-market-tactic-routing` 把已经结束的结果归因到原始战略截止点与当前目录版本，持久化带内容地址的结果和不可变聚合代际，并拒绝未来可见证据。带版本的确定性路由器只读取有界战绩，应用硬资格门槛与固定证据阈值，并输出前三战法、分数组成、证据引用、拒绝原因、风险上限和现金下限。

每项结果、战绩和路由都具有内容身份；开闭截止区间更新阻止未完成结果向前泄漏；有界日期分区避免读取完整历史；条件证据缺失、样本不足、成本脆弱或成交质量较差时，`defensive_no_trade` 胜出。确定性记录无需调用模型即可回放与比较；P2 负责模型辅助比较。

### P2——DSH 统帅、否决与逐日归因

P2 只向 DSH 统帅提供确定性的前三名单和最小充分专家证据。统帅最多选择一个主战法和一个辅助战法；宿主校验拥有范围与风险上限，独立审查者保留最终否决权。逐日推进回放随后分别归因确定性路由、DSH 综合、选股、执行和否决的增量价值与成本。

当每项模型辅助决策均符合截止点且可回放，未知或未晋级行动失败关闭，标准模式避免完整历史扫描和非必要专家，并且完整选择器扣除切换成本后优于预登记的固定及含空仓基准，才允许晋级模拟，P2 通过验收。

<a id="dev-note"></a>
## 开发注记

P0 和 P1 提供共享身份、条件证据与确定性路由基础；P2 仍为拟议阶段。现有固定战法与路由结果仍是研究证据，不能证明模型辅助选择具有增量价值。下一段封存日期范围、P2 提示词、模型路线和归因比较仍属于各实施变更及其 Agent Note 所拥有的预登记决策。
