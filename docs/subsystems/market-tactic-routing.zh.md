# 市场战法路由子系统

[English](market-tactic-routing.md) | 中文

市场战法路由子系统把已经结束且符合截止点的战法观察转化为不可变条件聚合与确定性前三名单，再根据该精确名单校验模型建议与独立否决。它位于[战法资格](market-tactic-eligibility.zh.md)之后、个股排序之前。实现位于 [`@deepseek-ai/dsh-market-tactic-routing`](../../packages/market/market-tactic-routing/README.zh.md)。

## 结果可见性

一项成熟结果记录主动目录战法与版本、原始决策日期、成熟日期、首次可用时间、原始有界环境、净收益与翻倍成本收益、回撤、成交率和精确来源哈希。`availableAt` 是可见性边界：一个战绩代际只接受上一截止点之后、当前截止点及之前的结果。环境从原始战略记录派生，因此已经实现的结果不能用之后的市场状态重新标记。

## 条件聚合

环境键包含带版本的市场状态、情绪周期、头部板块结构、波动代理、拥挤度区间与执行质量区间。每个战法版本和精确环境单元保存充分统计量，用于计算样本数、期望与方差、胜率与盈亏比、最大回撤、成交率、翻倍成本期望、近期指数有效性和最近可用结果。一个代际只包含这些有界单元、上一代际身份和本次新增结果身份。

`TacticRoutingStore` 按 UTC 可用日期分区持久化结果，并按内容身份保存战绩。增量补齐只枚举两个显式截止点之间的日历分区；超过调用方最大跨度时会失败。日级路由器消费一份精确战绩身份，从不扫描结果文件或市场日线。

## 确定性路由

v2 路由器首先应用 P0 资格与精确目录版本校验，随后选择至少包含八个成熟样本的最窄证据层：精确环境、市场状态加情绪周期，或同一市场状态。证据绝不跨越市场状态边界。主动战法仍然需要为正的 95% 期望下界、为正的翻倍成本期望、不低于 50% 的成交率，以及为正的得分。名单记录所选证据层，并分别保留每项正负分数组成。修改阈值、证据层、分桶、衰减或权重时，必须创建新的路由器或环境版本。

合格战法与 `defensive_no_trade` 按稳定得分和战法 ID 顺序竞争。名单最多包含三项；即使防守候选排在三项正分主动战法之后，仍可通过独立字段访问。研究与模拟晋级状态保持显式：研究候选的模拟仓位上限为零。记录把当前快照、资格引擎、战绩、路由器、环境、分数组成、证据引用、被拒战法、风险上限和现金下限保存为回放身份。

## 统帅决策

统帅可以选择一项主名单成员和一项不同的可选辅助成员。防守只能作为主战法，且不能带辅助战法。建议证据必须属于所选候选，反证必须属于名单或其防守回退。宿主根据目录与名单事实派生范围、最大模拟仓位和现金下限，不接受模型文字声明。独立否决会把最终选择替换为防守。

名单与决策均具有内容身份。`TacticRoutingStore` 只有在引用名单已经存在且完整记录能够根据该名单通过校验后，才发布决策。因此，回放可以分别识别确定性可用性、模型建议与最终风险行动，无需信任序列化派生字段。

## 失败语义

本子系统拒绝未来可见结果、目录版本漂移、一次更新中的重复结果、未推进的截止点、晚于战略截止点的战绩、来自其他快照的资格、不可用战略组件、缺失防守、名单身份漂移、名单外战法或证据、与晋级不一致的范围和矛盾否决字段。缺少或较弱的条件证据不是异常：主动战法会得到明确拒绝原因，并由防守胜出。
