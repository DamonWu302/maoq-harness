# 市场战略状态子系统

[English](market-strategic-state.md) | 中文

市场战略状态子系统把不可变日级观察转换为可回放的 P2 特征，再依据精确证据引用校验独立的模型解释。它实现 [MAOQ 路线图](../maoq-roadmap.zh.md)中的战略状态边界，不排序股票，也不授予执行权限。

## 确定性特征记录

`StrategicFeatureRecord` 标识当前快照、有序历史快照哈希、结构版本、引擎版本、交易日和截止点。其证据目录以 `snapshot:<contentHash>#<path>` 寻址每个观察，并保存观察值。特征引擎不读取环境时钟，且在计算前排序历史，因此相同快照哈希与引擎版本会产生相同规范输出。

记录包含三个可独立测试的 `StrategicComponent` 值。就绪组件包含计算值和证据引用；不可用组件包含稳定原因码，且不能替换为默认值。只有市场状态、情绪周期和板块战场全部就绪时，`eligibleForInterpretation` 才为 true。

## 市场状态与情绪周期

市场状态计算器产生 `risk_on_trend`、`rotation`、`high_volatility_divergence`、`risk_contraction` 或 `repair`。输入为上涨占比、主要指数平均涨跌、涨跌停平衡、炸板压力和亏钱效应比率。

情绪计算器产生 `startup`、`acceleration`、`climax`、`divergence`、`ebb` 或 `repair`。输入为连板高度、晋级率、炸板率、亏钱效应比率和上涨占比。阈值属于 `STRATEGIC_ENGINE_VERSION`；阈值变化必须创建新引擎版本并更新金标夹具。

## 板块战场

板块比较需要当前快照，以及至少两个使用相同板块分类版本的历史快照。它计算强度、持续性、容量、催化支持、内部宽度、龙头质量、拥挤度、阻力和确定性综合得分。每个板块都携带这些维度使用的证据引用。

输出按综合得分和稳定板块 ID 排序。它不输出成员、龙头、候选或股票排名。历史缺失或不兼容只会使板块组件不可用，并阻止产生可行动的战略姿态。

## 解释边界

`StrategicInterpretationDraft` 必须给出主要矛盾、阻力最小的战场、支持证据、反证、可证伪切换条件、置信度、合格姿态和毛选方法应用。宿主拒绝空证据集合、重复或未知引用、无效置信度、缺失切换条件，以及没有证据或适用边界的方法应用。

`buildStrategicStateRecord()` 接收显式决策时间和最大时效，不读取进程时钟。过期、时间不一致或残缺的特征记录只能产生 `no_trade`；即使声明了更积极的姿态，置信度低于 `0.5` 仍不可行动。最终记录分开保存确定性特征和解释，使回放能比较模型变化而不改变计算事实。

## 毛选方法归因

模型只能选择 `MaoMethodId`，并填写本次应用、证据引用和适用边界。`MAO_METHOD_CATALOG` 在校验后提供篇目、来源 URL 和中文方法摘要。每条解析后的归因都携带 `attributionKind: paraphrase`；系统不会把摘要呈现为特定版本的逐字引文。

初始目录覆盖调查先于结论、实事求是、主要矛盾、具体分析、实践检验、集中优势，以及主动性—灵活性—计划性。该映射是用于市场研究的分析方法类比，并不声称这些篇目讨论证券交易。
